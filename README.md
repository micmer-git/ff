# ff

## Weekly Futuro Fortissimo drafts

The [weekly editorial workflow](editorial/WEEKLY_WORKFLOW.md) turns selected
OpenClaw/Discord links, notes and screenshots into unpublished Substack drafts.
Start with [agent instructions](AGENTS.md) and [FF style](editorial/STYLE.md).
It includes portable setup, source verification, image handling, draft recovery
and the scheduler prompt. Private intake and drafts stay outside version control.
